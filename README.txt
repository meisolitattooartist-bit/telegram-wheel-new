مینی‌اپ مستقل گردونه — تک‌فایل index.html
برای بازشدن داخل Telegram Mini App، فایل باید از طریق HTTPS سرو شود و آدرس آن به دکمه/منوی وب‌اپ تلگرام وصل باشد.
صدا از قابلیت گفتار مرورگر استفاده می‌کند؛ کیفیت صدای فارسی به صدای نصب‌شده روی دستگاه وابسته است.
این نسخه برای یک اجراکننده است؛ انتخاب برنده با crypto.getRandomValues در مرورگر انجام می‌شود، اما تضمین ممیزی مستقل یا ضد دست‌کاری مطلق نمی‌دهد.
